# Tajawal — مستضاف محلياً

الملفات هنا هي نفس ملفات Google Fonts (Tajawal v12) بلا إعادة توليد، نُقلت
إلى الأصل نفسه لسببين:

1. **حذف الرمشة عند الفتح.** التحميل من `fonts.googleapis.com` يحتاج مصافحة
   TLS مع نطاق ثالث ثم رحلتين متسلسلتين (ملف CSS ثم ملف الخط)، فيرسم
   المتصفح النص بالخط الاحتياطي ويبدّله بعد وصول Tajawal. من الأصل نفسه
   تصل الملفات مع بقية الحزمة، و`rel=preload` في `index.html` يبدأ طلب
   الأوزان الظاهرة قبل تحليل CSS.
2. **بلا طرف ثالث.** لا طلب يخرج إلى Google في كل زيارة.

## الأوزان

خمسة أوزان (400/500/700/800/900) كما كانت في الرابط القديم حرفياً، وكل وزن
ملفّان: `-arabic` و`-latin`، لكلٍّ `unicode-range` خاصّ به في
`src/index.css` — فملفات اللاتيني لا تُنزَّل إلا عند أول حرف لاتيني.

المسبوقة بـ preload أربعة فقط (العربي 400/700/800/900): 500 قليل الاستعمال،
واللاتيني يُطلب عند الحاجة.

## التحديث

```
curl -A "Mozilla/5.0 ... Chrome/120.0" \
  "https://fonts.googleapis.com/css2?family=Tajawal:wght@400;500;700;800;900&display=swap"
```
ثم نزّل روابط `woff2` منه بالأسماء نفسها هنا، وحدّث `@font-face` في
`src/index.css` إن تغيّر `unicode-range`.
